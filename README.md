# nlp_assignment_2

## Clone Repository

Clone with all submodules recursively:

```bash
git clone --recurse-submodules https://github.com/paulnagle/nlp_assignment_2.git
```

If already cloned without submodules:

```bash
git submodule update --init --recursive
```

## Project Structure

- `iwslt2026_ga-eng/` - Training and test data (submodule)
- `doc/` - LaTeX documentation
- `R00065426_Paul_Nagle_NLP_Assignment2.ipynb` - Main notebook

## Requirements

Training data is stored in submodules and must be cloned recursively.
